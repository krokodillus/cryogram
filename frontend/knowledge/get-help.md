# Find instructions and get help

**Information** contains the workflow's purpose, instructions and version history. **Knowledge** explains the controls in more detail, and **Help & feedback** opens the support page. If a failed run offers a problem report, you can review it before deciding whether to send it.

For one workflow, start with **Run history** and **Issues**. For help with Cryogram itself, **Help & feedback** opens the support page: describe what you did, what you expected and what happened.

After a run stops with an error, **Share what happened with Cryogram?** shows the full problem report. Choose **Yes, share it** to send it or **No** to keep it private. Turn off these questions under **Admin > Preferences > Offer to send a problem report**.
