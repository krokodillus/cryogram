# Connect to external tools and third-party apps

Connect through APIs, databases or other interfaces to the systems you need to work with. Integrations are not pre-built: Cryogram uses official documentation, skills and its own learnings to set up consistent connections. It tests and checks all output, helping it catch problems and fix the connection if anything changes.

Tell Cryogram which system you want to connect to and what it should read or write. Provide any documentation or example records you have, and enter access keys in the separate secret box when asked.

Review the proposed steps before approving the build. Cryogram asks before trying sends for real; if you decline, the step can still be built and first tried when you run the workflow.

If access expires or a service changes, open **Issues** and choose **Investigate**. Include what changed, if you know, and review the proposed fix before continuing.
