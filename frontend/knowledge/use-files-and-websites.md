# Work with files and websites

Workflows can use files on your computer and open a browser to read and interact with websites. Sign in when asked; each workflow remembers its own browser login for later runs.

A file input can be a stored copy or a path to a file on your computer, depending on how the step was built. Ask in the chat to change this: a copy suits a fixed reference, while a path suits a file that changes. Keep files where the workflow expects them, or update the path if you move them.

Browser steps need Chrome, Chrome Beta, Chromium or Edge installed. Sign in through the window when asked. The login is remembered for that workflow's later steps and runs; attaching an environment does not share its browser login.
